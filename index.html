Conference Papers

  1. NeurIPS
    2026

    FASD: Hardware Acceleration for Multi-AI-Agent Discussion

    Rui Chu, Kaiyuan Zhang, Antian Wang, Yingjie Lao

    Advances in Neural Information Processing Systems 39 (NeurIPS 2026). To appear.

    First author
    Summary

    An FPGA–algorithm co-design framework that cuts the latency of discussion in LLM-powered multi-agent systems. It models multi-agent discussion as a graph-coupled dynamical system so agent-activation pruning can be optimized through phase-coupled dynamics, then maps the pruning operator onto an FPGA-friendly datapath. Efficiency improves while task performance is preserved, with larger gains as the agent graph grows.

  2. EMNLP
    2026

    AegisCodeGen: Toward Copyright-Aware Code Generation with Runnability-Guided Fusion

    Rui Chu, Nicole Meng, Tanusree Das Tithy, Thomas Cao, Faysal Hossain Shezan, Yingjie Lao

    Proceedings of the 2026 Conference on Empirical Methods in Natural Language Processing (EMNLP 2026). To appear.

    First author
    Summary

    Treats copyright protection for code LLMs as region-aware generation control. Multiple sampled generations build an agreement profile over the target program, which then gates copyright-aware logit fusion: stronger protection in low-agreement regions, weaker shifts near executable anchors. Protected-code reproduction drops while runnability and utility are preserved, with no retraining and no access to training data.

  3. ECCV
    2026

    HAS: Highlight-Guided Attention Steering for Multimodal LLM Video Summarization

    Rui Chu, Yingjie Lao

    Computer Vision – ECCV 2026, Lecture Notes in Computer Science, pp. 138–157. Springer.

    First author Paper arXiv Interactive demo Acceptance rate 27.5%
    Summary

    Replaces discrete key-frame selection with a continuous, frame-level highlight distribution computed over the whole video, and injects it at inference time as an attention steering vector. The multimodal LLM attends more to highlighted frames while still retaining information from the rest of the video.

  4. NeurIPS
    2025

    BAM-ICL: Causal Hijacking In-Context Learning with Budgeted Adversarial Manipulation

    Rui Chu, Bingyin Zhao, Hanling Jiang, Shuchin Aeron, Yingjie Lao

    Advances in Neural Information Processing Systems 38 (NeurIPS 2025), pp. 15819–15850.

    First author Paper OpenReview Acceptance rate 24.5%
    Summary

    A two-stage budgeted attack on in-context learning: an offline, gradient-based stage learns how to distribute the perturbation budget across in-context examples, and an online stage perturbs examples one by one as they arrive, a stricter threat model where only the current example can be modified. It achieves higher attack success and stealthiness while keeping text quality, and the adversarial examples transfer to other models.

    DebiasRAG: A Tuning-Free Path to Fair Generation in Large Language Models through Retrieval-Augmented Generation

    Rui Chu, Bingyin Zhao, Thanh Quoc Hung Le, Duy Cao Hoang, Huawei Lin, Ping Li, Weijie Zhao, Khoa D. Doan, Yingjie Lao

    First author arXiv Code
    Summary

    A tuning-free, query-specific debiasing framework built on retrieval-augmented generation. It derives debiasing contexts from self-diagnosed bias contexts and reranks retrieved context with gradient-updated debiasing guidance, reducing social bias (race, gender, age) while preserving the model's representation ability.
