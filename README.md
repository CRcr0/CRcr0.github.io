# crcr0.github.io

Personal academic homepage of Richard Rui Chu, served at <https://crcr0.github.io/>.

- `index.html`: the whole site (HTML, CSS, and a small publication filter script). No build step.
- `cv/Richard_Rui_Chu_CV.pdf`: public copy of the CV (phone number removed). Source: `2026Fall_CV_V3_ScottStyle_FullPubs/main.tex` in the private resume repository.

To update, edit `index.html` (or replace the PDF) and push to `main`; GitHub Pages redeploys automatically.
